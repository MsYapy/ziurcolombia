# Screenshots

Para agregar el screenshot del catálogo:

1. Guarda la imagen del screenshot como: `catalog-screenshot.png`
2. Colócala en este directorio: `docs/images/`
3. El README.md ya está configurado para mostrarla automáticamente

La imagen debe mostrar:
- Catálogo de Movimientos con la tabla de datos
- Sidebar con el menú "Catálogo"
- SearchBar con el texto "Buscar por código o descripción..."
- Grid mostrando los movimientos (código, descripción, estado)
- Registros: 39 de 39 en la esquina superior derecha
